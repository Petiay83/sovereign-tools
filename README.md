## 🔒 Radical Privacy Guarantees

* **100% Client-Side Execution:** Zero database, zero telemetry scripts, zero tracking cookies. All financial records, medical biomarkers, and personal reflections exist only in your browser's local RAM.
* **No Cookie Consent Banners:** Because we never store or transmit cookies, there is zero GDPR/ePrivacy tracking bloat.
* **Offline-Ready Progressive Web App (PWA):** Installable on iOS, Android, macOS, and Windows. Works completely offline on flights or remote co-working spots.
* **Zero External Dependencies:** Built with pure Vanilla JavaScript, HTML5, and Tailwind CSS.

## 💻 Local Development & Build Engine

The entire platform is built with an automated static generator `build.py`:

```bash
# Clone the repository
git clone https://github.com/Petiay83/sovereign-tools.git
cd sovereign-tools

# Build all micro-tools, Hub portal, sitemap, RSS feed, and PWA assets
python build.py

# Build and deploy directly to GitHub Pages
python build.py --deploy

# Ping search engines via IndexNow protocol (Bing, DuckDuckGo, Yandex)
python build.py --indexnow
```
